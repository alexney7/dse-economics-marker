# 得分點與經濟推理

## 本題規則卡

先建立再評答案；表格不是要求每題固定分成相同數目的點。

| 欄位 | 要記錄的內容 |
|---|---|
| 題目識別 | 年份、版本、卷別、題號／小題、滿分 |
| 來源 | 評分參考檔名、PDF 第幾頁（1 起算）、印刷頁碼、適用勘誤 |
| 得分要求 | 概念、推理、結論、計算、圖示各需什麼證據 |
| 分配 | 本點分值、分組最高分、替代選項、前置條件 |
| 特殊處理 | 是否容許跟隨錯誤、數值容差、單位、等價答案；沒有寫明就不擅定 |
| 狀態 | 官方／題目提供者細則；教師已確認細則；未確認草案 |

評分採獎分點，不另創「錯一句扣一分」規則。逐點相加若超過小題上限，先核對是否替代答案／分組上限，不能默默截斷掩蓋解析錯誤。

## 可以跨題使用的檢查方法

- **解釋／分析**：識別題目條件、改變的變量、因果機制、結果；找出缺失的連結。不是所有答案都必須寫完整四段，是否需要及如何給分依本題細則。
- **比較／評價**：核對比較對象、指標、成立條件、相反影響及結論。不要把其他考試體系的固定論文評分層級移植到 DSE。
- **計算**：分開核對公式、代入、運算、單位、百分比基數與結論。結果錯不等於所有步驟零分；結果對也不自動滿足指定展示步驟。後續連帶錯誤只按本題規則判斷，規則未明且會影響分數時交教師裁定。
- **圖示**：辨識坐標變量、曲線標籤、移動／沿線變動、方向、初始及新均衡、相應價格與數量、面積含義。依題目要求給分，不因線條不美觀扣分，不補上學生沒有畫出的曲線。若文字和圖互相矛盾，定位矛盾，按細則或交教師裁定。
- **列表**：保持行列標題、數值與單位對應；重建總量、平均量、邊際量的關係。不能將 OCR 讀錯一格造成的整列錯誤直接歸咎學生。
- **等價表達**：比較命題含義、條件與因果方向。同義且涵義完整可以給建議分；實質不同但可能成立的替代分析，列出支持及疑問讓教師決定。

## 不可跨題直接繼承的規則

某題每點 2 分、最多兩點、必須繪圖、指定兩項原因、文字與圖重複是否另計等，均只對來源題適用。年份不同或模考改寫，即使主題相同，也須重新建立本題規則卡。

## 來源衝突

先查對本題／語言／版本和適用勘誤。確定適用的官方勘誤應更新原細則，不繼續把已更正內容當作有效標準。若仍有教材與細則或兩份細則之間的實質衝突：保留兩種解讀、影響分值、來源位置，將受影響點設為待教師確認；不得自行覆蓋或給最終結論。

## 用現有資料校準

先隱去樣本的等級標籤，按本題細則提出建議分，再閱讀官方評語比較概念、分析及圖表判斷。樣本沒有官方小題實得分時，只能稱「定性對照」，不能計算分數準確率。這不需要新出題；有教師已批答卷時再計算逐點差異及原因。
