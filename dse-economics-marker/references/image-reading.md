# 圖像讀取與掃描資料

## 頁面處理

1. 建立頁面順序、題號及續頁對應；保留原件。核對四邊、圖表、題幹、頁碼是否齊全。不同學生分開處理。
2. 預覽整頁後，必要時旋轉、放大或裁切副本。先看字的方向，不能只相信 PDF rotation。現有教材的旋轉資訊不一致，逐頁確認，不整本盲轉。
3. 可用 `python scripts/pdf_pages.py inspect --pdf "來源.pdf"` 檢查文字層；沒有文字層不代表沒有內容。
4. 可用 `python scripts/pdf_pages.py render --pdf "來源.pdf" --pages 2,4-6 --out "工作目錄" --rotation 0` 匯出頁面。頁碼均為 PDF 1 起算；rotation 可省略以保留原設定，也可指定 0/90/180/270 的絕對 PDF 旋轉值。查看圖片後再調整。工具只渲染／提取已有文字層，不自動 OCR。
5. 由具備圖像能力的模型閱讀圖片，或在可用的 OCR 工具中識別後視覺核對。若環境不能看圖且無可靠 OCR，停止該部分評分並請求可讀內容。

## 證據記錄

記錄檔名、PDF 頁碼、印刷頁碼、題號、區域（如右下圖表或第三行）。只有確實查看過的原文才可引述；模糊內容用「[未能辨認]」，不可依標準答案補字。

手寫正負號、分母、下標、百分比、交點標籤以及表格行列，須對照放大原圖。批改痕跡與學生文字分開。勘誤中的刪除線／新增字必須看圖，文字提取可能把新舊字黏在一起。

## 圈註與待確認

有可用圖像標註工具時，在副本圈出有爭議位置並編號；不能修改原卷。沒有標註工具時，用頁碼＋題號＋行／區域＋必要短引文，清楚定位，不聲稱已圈圖。

每個疑點記錄：編號、原因、需要確認的內容、受影響得分點、待定分值、相關來源。可確定的其他題繼續批；不清楚不是答錯，缺頁不是空白。

## 教材整理

先用章節索引定位，再讀相關段落和圖表。保留「概念／条件／推理／常見錯誤／來源頁碼／核對狀態」。沒有完整核對的 OCR 內容標為草稿，不作給分規則。教材版本不同時重新確認頁碼和課程適用性。
