# HTML 評估報告與成績分析

## 交付方式

完成批改後，預設生成一份可直接用瀏覽器開啟、離線閱讀的獨立 `.html` 檔案。對話只給摘要、待教師處理事項及檔案連結，不能以聊天中的 Markdown 或 HTML 程式碼塊代替成品。使用者明確指定其他格式時遵從其要求。

沿用既有報告輸出目錄；沒有指定時使用當前工作區的 `outputs`。檔名採學生代號、試卷年份／名稱及報告版本，避免覆蓋其他學生報告。不能寫檔時明示限制，不聲稱已產出。報告仍可在分數待確認時生成，但標題及分數卡清楚標「建議評估／待教師確認」。

以 UTF-8、`lang="zh-Hant"`、viewport 及內嵌 CSS 製作；圖表用內嵌 SVG 或 CSS，不依賴 CDN、網絡字體或外部圖表服務。必要的圖片嵌入檔案，使 HTML 移到其他電腦仍可閱讀。學生原文與來源文字必須 HTML escape，不能作為可執行標記或脚本插入。報告只包含本學生的資料，不自動上傳或公開。

## 先整理唯一的評分資料

圖表、表格及文字摘要必須由同一份逐點資料計算，不各自手填。按需要用本機程式整理並生成 HTML。每個可獨立計分的評分單位記錄：唯一編號、卷別／部分、題號、主要知識點、滿分、建議分或 null、教師確認分或 null、狀態（建議／已確認／待裁定／缺資料）、學生證據、評分來源、失分原因及改進行動。確認零分與未知分數不可混淆。

- 知識點依適用課程及題目要求分類，例如機會成本、需求與供應、彈性、國民收入；分類不确定時用「綜合／待分類」，不硬猜。
- 跨知識點題目若細則有獨立得分點，按得分點拆分；無法拆分時只歸一個主要知識點或「綜合」，其他標籤僅供搜尋。同一分值不可在總體知識點統計中重複計數。
- 替代得分點、任選答案及組合上限先按 marking.md 處理成有效計分單位，不能把所有可選細則的滿分相加。未選的選修題不計入應答分母；確認應答但空白才算零分。
- 原始分用於題目及知識點診斷；整科加權分另按年度規則計算。兩者分開顯示，不把知識點原始分佔比當成整科權重。

## 指標與圖表

### 1. 知識點得分率：水平條形圖＋明細表

對每個知識點，以「可計算單位的得分合計 ÷ 同一批單位滿分合計 × 100%」計算，不能平均各小題百分比。例如 1/2 與 8/10 應為 9/12＝75%，不是 65%。

預設展示建議口徑：已確認單位用確認分，其餘可判單位用建議分，圖題標「含未確認建議分」。另列已確認分與確認覆蓋率；可依需要提供切換，切換後分子與分母必須同步限定在相同單位。

每行顯示得分／滿分、百分比、涉及題號、獨立小題數、待定滿分及計分覆蓋率。覆蓋率＝可計算單位滿分／本知識點已知應答滿分。待裁定／缺資料單位不算零分；排除它們後必須標「可判部分得分率」，不稱完整知識點成績。缺頁使應答滿分未知時，覆蓋率寫「無法計算」。

分母為零或未考查時顯示「未考查／暫無可計算資料」，不顯示 0%。所有條形圖用共同 0–100% 刻度，直接標數字，不只靠顏色。只有一題支持時標「樣本有限」，不把本次得分率稱為整體掌握概率。

### 2. 各題得分：得分率圖＋原始分表

按題號展示各小題得分／滿分及狀態；完整可判題畫得分率，受未決項影響的題用文字「部分可判／待裁定」或有依據的區間。不同滿分題目用百分比比較，旁列原始分。只有單題時可縮減圖表，不捏造其他題目以湊圖。

### 3. 失分原因：有證據才生成

把已可確定失分歸為概念、情境應用／因果論證、圖表、計算、表達或確認漏答等，展示失分值及相關題號。每一失分單位只能分配一次主要原因；不能拆出具體分值時改列受影響題數，明確標單位，不能假裝是失分佔比。待裁定分值不算已失分。已確認失分與含建議分的失分須標明口徑；證據不足則不畫此圖。

沒有班級或歷次資料，不生成排名、百分位、班級平均、進步趨勢或統計置信度。不同卷的難度未校準，不把分數差直接稱為能力增長。

## 報告結構

1. **試卷評估摘要**：學生代號、年份／課程版本、卷別、資料完整性、分數狀態、原始分及有條件的加權分／等級。缺卷不補零湊整科。
2. **成績分析**：上述圖表與相同數據的可讀表格；解釋樣本量、覆蓋率及計分口徑。
3. **逐題回饋**：保留 feedback.md 的學生證據、得分依據、分值、具體修正與示範。可用原生 details 折疊並以題號錨點連結圖表。
4. **優先改善事項**：依有證據的失分、重複錯誤及前置概念，給最多三項具體行動，連到題號與教材章節；不要只按低百分比認定弱項，不為湊三項而虛構。
5. **教師復核**：待裁定清單、影響分值及待確認事項。學生版仍保留影響結論的不確定性。教師回覆後同步重算表格、圖表及摘要。
6. **來源與方法**：評分資料頁碼、課程版本、加權算法、cutoff 的第三方性質、情景假設及圖表口徑。

## 閱讀與交付檢查

- 手機寬度下單欄排列；長表格可水平捲動；正文具足夠對比，圖表有標題、文字說明及數據表。若有互動，需支援鍵盤，關閉 JavaScript 後核心內容仍可讀。
- 提供列印 CSS，列印時展開逐題內容、隱藏操作按鈕，避免圖表被截斷。
- 核對各計分單位唯一、知識點滿分／得分可回加到同範圍題目合計、無超分、無 NaN／Infinity、待定未當零分、圖表與表格一致。百分比僅顯示時四捨五入，不影響等級比較。
- 有瀏覽器工具時檢查桌面、手機和列印視圖；沒有時完成資料與 HTML 結構檢查並說明未作視覺驗證。只報告實際完成的驗證。
